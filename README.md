# Ex-Omni-2D Project Page

Static project page for:

> **Ex-Omni-2D: Expressive Omni-Modal Dialogue Models with Native Visual Presence**

## Publish with GitHub Pages

1. Create `LOGO-CUHKSZ/Ex-Omni-2D` on GitHub.
2. Upload the **contents of this directory** to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. The page will appear at:
   `https://logo-cuhksz.github.io/Ex-Omni-2D/`

No build step or third-party framework is required.

## Before the public release

- Add the final paper PDF and change the Paper button in `index.html` to a link.
- Verify the GitHub code URL.
- Replace the provisional BibTeX with the final publication metadata.
- Add compressed MP4 demos under `assets/videos/` if desired.

For best GitHub performance, keep each media file below 25 MB and each individual
repository file below GitHub's 100 MB hard limit.
